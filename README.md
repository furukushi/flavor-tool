# フレーバーツール

「キャラチャット」で使う **フレーバー** を作成・管理するためのツールです。

フレーバーとは、キャラクター設定に追加で渡すプロンプト情報のことです。舞台となる場所、登場人物同士の関係性、その場の状況や時間帯、キーアイテムなど、掛け合いの前提条件を1つのまとまりとして定義し、チャットに貼り付けて使います。

## できること

### フレーバーの管理
- フレーバーの作成・編集・複製・削除
- 各フレーバーは次の項目を持ちます
  - **名前**（必須）
  - **カテゴリ**（複数選択可）
  - **概要**
  - **影響度**（0〜100%）
  - **追加説明**（項目名＋役割の自由項目。役割は 事実 / 振る舞い / 禁止 / 条件 / 具体例 / その他 から選択）
- カテゴリを選ぶと、そのカテゴリに登録されたデフォルト項目が自動で補完されます

### カテゴリ管理
- カテゴリの追加・編集・削除と、カテゴリごとのデフォルト項目の設定
- 初期カテゴリは **場所 / 関係性 / 状況 / 時間 / 小道具** の5つ

### 影響度と指示文
- 影響度は7段階の指示文に変換され、出力テキストに「AIへの指示」として含まれます（例: 85〜100%なら「最優先で厳密に反映すること」）
- フレーバーごとに「キャラ設定を無視する」オプションがあり、オンにすると矛盾時の扱いが影響度の段階に応じて変わります（中程度なら矛盾しすぎない範囲で混ぜる、最大ならフレーバーを優先してキャラ設定を無視する）

### テキスト出力
- フレーバーをテキスト形式でコピーし、キャラチャットへ貼り付けて使います
- コピーに成功すると「クリップボードにテキストをコピーしました」と表示されます

### JSONの書き出し / 取り込み
- 全フレーバーをJSONで書き出し・取り込みできます（バックアップや環境移行用）
- 取り込み時に未知のカテゴリがあれば自動で登録されます

### AI自動生成
- 編集画面から、土台にする項目（入力済みのカテゴリ・概要・影響度・追加説明）と方針リクエストを指定してキューに投入できます
- Muse側がキューを確認して自動で生成し、結果でフレーバーを上書きします
- 「既存項目の文脈を考慮する」設定で、土台以外の既存内容を生成に含めるかどうかを選べます
- 生成中も含めていつでも強制キャンセルでき、キャンセルされた結果は反映されません
- 実行履歴はフレーバーを削除した後も残ります

### 一覧の表示
- 並び替え（五十音順 / 最近使用した順）
- 表示モード（通常 / カテゴリ別）
- 表示の細かさ（簡易 / 詳細）
- 名前・概要・カテゴリでの検索
